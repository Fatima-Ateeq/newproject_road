# RoadWatch AI

AI-assisted road and traffic complaint management. Citizens report and track problems;
administrators review them with help from an AI triage agent (added in Milestone 5).

```
RoadWatch_AI/
├── backend/        FastAPI + PostgreSQL API (this milestone)
├── docs/           Decision log, later the SRS and overview
└── (frontend/, ml/ are added in later milestones)
```

See [backend/README.md](backend/README.md) for setup and the API.
